# Support

Need help with Willow? Here's where to look, in order.

## 1. Documentation first

Most questions are answered in the docs:

- **[README.md](README.md)** — what the app is and how to run it
- **[docs/](docs/README.md)** — per-service wikis (API + Neon, Vercel, R2, CI/CD, OpenAI)
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — how the pieces fit together
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — local setup and DB workflows

## 2. Check existing issues & discussions

Before opening anything new, search for an existing thread:

- [Issues](https://github.com/imsudip/willow/issues)
- [Discussions](https://github.com/imsudip/willow/discussions)

## 3. Ask in Discussions

For "how do I…" questions, ideas, and help with self-hosting, open a
[discussion](https://github.com/imsudip/willow/discussions). Include:

- What you're trying to do
- What you've tried
- Relevant logs / error messages (redact secrets!)

## 4. Open an issue (bugs / feature requests)

Use the issue templates — they'll ask for the exact info needed (device,
browser, web/API/sync area, steps to reproduce).

## 5. Security vulnerabilities

**Do not** open a public issue for security problems. See
[SECURITY.md](SECURITY.md) for the private reporting process.

---

This is a hobby project — please be patient and kind. Maintainers respond as
time allows. 💜
