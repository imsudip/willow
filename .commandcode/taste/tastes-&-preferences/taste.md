# Tastes & Preferences
- Wants smooth, GPU-accelerated (shader/WebGL) visualizations over CPU-driven canvas rAF loops — picked LiveKit's `AgentAudioVisualizerAura` (WebGL shader, zero per-frame React re-renders/DOM writes) specifically because the canvas waveform was janky. Confidence: 0.8
- Prefers adopting the user's chosen, officially-documented solutions (e.g., LiveKit Agents UI prebuilt components from docs.livekit.io) and reusing them beyond their intended scope (feeding a local mic `LocalAudioTrack` with a fixed `"listening"` state, no LiveKit server) rather than second-guessing the choice; "I really like LiveKit docs › …" is treated as a directive to wire it in. Confidence: 0.75
- Tolerates significant bundle-size increases from a component the user explicitly picked (LiveKit aura visualizer: ~100KB+ deps, ~1.38MB precache) as long as it fixes the perf complaint — but expects the agent to flag the size cost and offer mitigations (e.g., lazy-loading the visualizer only when recording starts). Confidence: 0.7
- Prefers visual polish in a warm golden aesthetic — aura visualizer color-graded to match the app's golden-hour palette (`#d99a3d` amber with subtle `colorShift`), consistent with the warm palette identity. Confidence: 0.7
- Prefers shadcn-CLI-installable component registries (e.g., LiveKit Agents UI `@agents-ui/*` components) integrated into the project via proper shadcn setup (`components.json`, `@/` path aliases in tsconfig + Vite) over manual copy-paste. Confidence: 0.6
- Prefers the agent to verify a new dependency's source/API before wiring it (read the component source to confirm it accepts a plain `LocalAudioTrack` without a provider), rather than assuming docs examples apply. The same verify-don't-assume discipline extends to props/theme handling: when a color or `themeMode` seems off, the user expects the agent to trace the prop through the component's internals (e.g., the shader's `uMode` uniform) to confirm it is actually being honored — the user asked to "check if it's actually taking the theme mode properly" before concluding the color prop is wrong. Confidence: 0.7
- Prefers not to be blocked by interactive CLI prompts — agent kills/answers them (e.g., piped `n`) and hand-creates the config file the CLI wanted, then retries. Confidence: 0.5
