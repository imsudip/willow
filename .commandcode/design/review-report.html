// PRIORITY ISSUES
P0 / HIGH

Dark mode is broken in practice

index.css:57-73 maps the semantic aliases to light tokens only; there is no @custom-variant dark and no .dark alias overrides. html.dark flips, but bg-canvas/90 (Shell.tsx:18) stays warm-cream with white text, and text-ink stays near-black. Settings → Dark renders an unreadable canvas.

FIX: Add @custom-variant dark and .dark overrides for canvas/surface/ink/muted/line/accent aliases so dark mode renders a warm charcoal surface.
P1 / MEDIUM

Flat type hierarchy

Every page heading is font-serif text-3xl font-medium (TodayScreen.tsx:63, EntriesScreen.tsx:38, StatsScreen.tsx:66, SettingsScreen.tsx:77, EntryDetailScreen.tsx:129). One size, one weight, repeated. The Lora variable font ships 400-700, so the range exists but goes unused.

FIX: Give the Today greeting a display size (text-4xl) at font-normal; settle tab screens at text-2xl.
P1 / MEDIUM

Card chrome spreads thin

StatsScreen.tsx:68-117 puts every stat in the same rounded-2xl border bg-surface p-5 card: streak, chart, calendar, mood list, digest. Equal weight, no hierarchy.

FIX: Let the digest sit on bg-accent-soft without a border so it reads as a letter, not a tile; tighten the mood list into a two-column grid.
P1 / MEDIUM

White glyphs on amber

RecordOverlay.tsx:167 (bg-accent text-white), SettingsScreen.tsx:151 (bg-accent-strong text-white), EntryDetailScreen.tsx:113 (bg-[var(--destructive)] text-white). Pure white on warm amber reads as a hard cut.

FIX: Use accent-strong for the mic/stop fills and a warm off-white (oklch 0.98 0.01 80) for glyphs; keep pure white only for true danger.
P1 / MEDIUM

Placeholder-only form fields

LoginScreen.tsx:39-65 and EntriesScreen.tsx:42-47 use placeholders as the only label for email, password, name, and search. Screen readers get no field name.

FIX: Add real labels (visually-hidden where appropriate) and aria-label="Search entries" on the search input.
P2 / LOW

Missing states in the record flow

TodayScreen.tsx:116-129 record CTA has no loading or disabled state; ReviewScreen.tsx:86-100 tabs lack aria-controls/aria-selected sync. Transcription failure leaves no retry or cancel.

FIX: Add a loading state to the record CTA; wire role=tablist with aria-controls and aria-selected on both tab groups; offer a retry path on transcription failure.
